# 参考资料预处理规则

当用户提供参考资料（PDF/网页/文本/DOCX/XLSX）时，按以下流程处理一次，后续不再读原文。

## 处理流程

1. **读取**：本地文件用 `python3 references/scripts/extract_text.py <路径>`（自动识别 PDF/DOCX/XLSX）；网页用 WebFetch；图片PDF 用 pdf-converter skill
2. **归类**：逐段扫描，只保留与报告章节直接相关的数据点和判断
3. **提取**：按 Ch{编号} 分组摘录，每条数据标注来源页码
4. **丢弃**：无关内容不保存不索引
5. **写入索引**：追加到 `reference_materials.md`

## 索引格式

```markdown
## [U1] {资料简称}
- **原文**：reference/U1-{文件名}.md
- **Ch1**：数据点 / 判断
- **Ch2**：数据点 / 判断
- …
```

## 引用方式

正文中：`……液冷渗透率达55%[U1]`
参考文献：`[U1] {标题} — {URL或文件路径}`

编号 [U1], [U2]… 独立于公开来源 [1], [2]…，互不冲突。

> **⚠️ 常见陷阱**：正文中可能同时出现 `[U1][3]` 等混合引用。写作时需注意**公开来源从 [1] 开始连续编号**，不要因为 [U1] 的存在而跳过 [1]。正确定法：`[U1], [1], [2], [3]…`（用户来源与公开来源各自独立，互不影响）。

## PDF 预处理技巧

用户给的 PDF 通常 30-100 页，**不必逐页精读**：
1. 先扫目录/小标题判断整体结构
2. 跳转到含关键数据图表的页面精读
3. 提取与报告章节直接相关的数据点
4. 剩余内容直接跳过
