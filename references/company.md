# 公司研究方法论（参考摘要）

## 核心框架：横纵分析法

**纵向分析（发展史叙事）：** 起源追溯 → 诞生节点 → 演进历程 → 决策逻辑 → 现状
**横向分析（竞品对比）：** 3 种竞品场景判断 → 核心差异 → 用户视角 → 生态位分析 → 趋势判断

**横纵交汇总结：** 演化阶段 + 历史路径解释 + 路径依赖判断 + 关键决策复盘

## 报告结构（11章）


## 分析工具

### 商业模式真实性验证
对照合同/财报验证"叙事 vs 实质"：

| 验证项 | 核心问题 |
|--------|---------|
| 收入模式 | 合同/财报中如何体现？是否独立列出？ |
| 客户锁定 | 续约率、客户集中度？ |
| 技术壁垒 | 专利/研发投入/人才密度？ |
| 规模效应 | 单位成本随规模下降趋势？ |

### 博弈地图
列出利益相关方，评估议价力和独占性资产：

| 利益方 | 评估维度 |
|--------|---------|
| 上游供应商 | 依赖程度、切换成本 |
| 下游客户 | 集中度、转换成本 |
| 监管机构 | 合规要求、牌照 |
| 资本方 | 融资节奏、估值 |
| 竞品 | 竞争强度、差异化 |
| 员工 | 吸引和留存 |

### 五链追问（定性框架）
顺序：客户路径 → 激励对齐 ↔ 竞争不对称 → 结构性地板 → 退出路径
财务生命力贯穿全程。

| # | 追问链 | 核心问题 | 危险信号 | 健康信号 |
|---|--------|---------|---------|---------|
| 1 | 客户路径 | 谁付钱？天花板？获客可复制？ | 单客户>80%、渠道集中 | 多客户类型、分散可复制 |
| 2 | 激励对齐 | 收入驱动正确行为？利益一致？ | 费用打包、不随成功增长 | 费用独立、双赢模式 |
| 3 | 竞争不对称 | 别人追不上什么？ | 先发无证据、技术可复制 | 数据飞轮、网络效应 |
| 4 | 结构性地板 | 最差怎样？不可改变的限制？ | 依赖无替代、监管不可控 | 替代路径、可管理约束 |
| 5 | 退出路径 | 谁收购？怎么兑现？ | 无收购方、现金流永远负 | 买方明确、逻辑清晰 |

**补充：结构性约束分类**（用于第4链）

| 类型 | 定义 | 能否改善 |
|------|------|---------|
| 内因问题 | 产品/团队/执行层面 | ✅ 可改善 |
| 外因约束 | 市场设计/监管/自然垄断 | ❌ 不可改变 |

**自检：** 内部解决还是外部结构？有绕过路径吗？市场结构在变吗？

### 六道算数（定量验证）

| # | 算数 | 公式 | 红线 |
|---|------|------|------|
| 1 | 真实毛利率 | （高毛利+服务收入）/总收入 | <15-20% |
| 2 | 核心LTV/CAC | ARPU×生命周期×毛利率/CAC | <2x |
| 3 | 次要LTV/CAC | 同理 | <1.5x |
| 4 | 资金消耗率 | 增长率×预付成本/可用资金 | >70% |
| 5 | 关键依赖度 | 最大渠道收入占比 | >80% |
| 6 | 极端存活 | （应收+预付）/（现金+授信） | >1.5x |

### 其他工具
- **技术护城河评估**：架构质量、数据壁垒、人才密度、IP组合、技术路线
- **客户画像**：人口统计、心理特征、痛点、目标、购买行为、异议、支付意愿
- **客户旅程**：认知→考虑→决策→上手→活跃→忠诚→流失
- **SWOT+五力**：SO/WO/ST/WT交叉分析 + 行业五力评分
- **定价策略**：竞争定价审计 × 价值定价 × 成本加成 → 三层定价设计
- **情景规划**：最佳/基准/最差/黑天鹅 4情境 + 概率 + 收入影响 + 战略应对
