# 行业研究方法论（参考摘要）

## 核心框架（5层递进）

```
第1层：市场结构     → 行业定义、市场规模、价值链全景
第2层：模式与类型   → 商业模式分类、定价机制、区域差异
第3层：竞争格局     → 主要玩家、市场份额、进入壁垒
第4层：经济学分析   → 单位经济、利润分布、结构性地板
第5层：趋势与判断   → 增长路径、风险、投资机会
```

每个层次向下兼容——做完第1层才能做好第2层。

## 市场规模交叉验证法

采用**自上而下 + 自下而上**两种方法交叉验证：

| 方法 | 逻辑 | 适用场景 |
|------|------|---------|
| **自上而下法** | 全球规模 → 按细分比例缩小 → TAM | 数据充足的成熟行业 |
| **自下而上法** | 单位经济 × 潜在客户 → 放大 → SAM/SOM | 新兴行业 |

**三层分解：** TAM（总可寻址市场）→ SAM（可服务市场）→ SOM（可获得市场）
**验证：** 两种路径差距 > 30% → 假设需重新审视。

## 价值链分析

**三步走：** 上游（供应商/成本驱动）→ 中游（公司定位/价值创造）→ 下游（渠道/终端客户）

**价值分配估算：** 每 $100 行业收入中，标注各环节利润占比。

**波特五力互补：** 价值链看利润分配，五力看议价力来源。每股力量打 1-10 分：

| 力量 | 评估方向 |
|------|---------|
| 供应商议价力 | 集中度、切换成本、前向一体化风险 |
| 买方议价力 | 客户集中度、转换成本、价格敏感度 |
| 同业竞争强度 | 市场集中度、产品同质化、退出壁垒 |
| 替代品威胁 | 功能替代性、性价比、切换意愿 |
| 新进入者威胁 | 规模经济、品牌壁垒、资本需求、监管壁垒 |

## 按市场/区域展开

每个市场按标准模块展开：市场结构 → 定价与价格趋势（3年对比表）→ 供应链/产能 → 监管与政策 → 玩家图谱 → 总结判断

**3年价格对比表**是核心模块。**区域差异显著**的市场必须分区展开。

## 技术分析

- 行业技术全景：核心技术路线、成熟度评估、瓶颈与突破
- 创新驱动力：R&D 投入、专利布局、产学研协同
- 技术对竞争格局的影响：路线分化、替代风险、标准化博弈

## 横纵分析（行业版）

**纵向（时间轴）：** 起源追溯 → 关键节点 → 决策逻辑 → 演化趋势
**横向（同期对比）：** 跨区域对比、跨模式对比、跨周期对比
**行业趋势全景图：** 6维度（宏观/微观/技术/监管/下游行为/资金流向）× 3时间线（短/中/长期）→ "所以呢"分析

**横纵交汇总结：** 行业演化阶段 + 确定性趋势 + 最大变量 → 综合判断
