# Card 6/7：最终校验

这是行业研究的最后一张卡。不写新内容，做完整报告的质量校验。

## 你的任务

读完整报告 → [N]校验 → 参考文献校验 → 跨章连贯性检查 → 格式审校 → 输出最终文件

## 工作流

### 1. 读取完整报告

读取：
- `{report_dir}/report_partial.md` — 全部 10 章
- `{report_dir}/sources.md` — 所有来源
- `../../research-methodology/references/workflow.md` — 校验规则

### 2. [N] 编号校验

1. 提取报告中所有 `[N]` 标记，去重排序
2. 与参考文献表的 1→N 条目逐一核对
3. 检查：每个正文中的 `[N]` 在参考文献表中有对应条目？参考文献表中每个编号在正文中被引用过？

### 3. 参考文献核验

1. 确保参考文献按 1→N 顺序排列，不分组
2. 每条记录格式：`[N] 标题 — URL`
3. 检查是否有重复来源
4. 移除注释类脏数据（无 URL 的行）

### 4. 跨章连贯性检查

1. 各章之间的逻辑连接是否自然？有无跳跃或断裂？
2. 关键数据和结论在各章中是否一致？（如 Ch1 的市场规模与 Ch9 的增长预测）
3. 有无重复内容（同一数据或论点在两章中出现）？
4. [N] 编号是否连续不冲突（跨章不重置编号）

### 5. 格式审校

1. 标题层级：`#` → `##` → `###` → `####` 是否完整跳级
2. 表格对齐标记 `:---` 是否完整
3. 报告头部信息是否完整（类型、覆盖期间、日期）
4. 无锚点链接 `(#xxx)`、无脚注 `[^1]`、无多余分隔线
5. 推测性内容是否标注了 `[推测]` 或 `（作者判断）`
6. 所有模糊时间（近期、最近、去年）替换为具体年份

### 6. 输出最终报告

将校验通过的内容输出为最终文件：
- `{report_dir}/{行业名}_Industry_Report_{日期}.md`
- **读取 `.card-progress` 中的 `completed_cards` 列表**，自动生成进度条：已完成→✅，未完成→⬜。不要手动输入 ✅/⬜，全部从进度文件推导
- 更新 `.card-progress` 标记全部完成

## 完成后

输出最终校验报告：

```
━━━ 最终校验报告 ━━━

✅ 章节：10/10 完整
✅ [N]编号：共{N}条，连续无中断
✅ 参考文献：{N}条，全部可访问
✅ 跨章一致性：通过（{N}处微调）
✅ 格式审校：通过
⚠️ 推测标注：{N}处标为推测

━━━ 项目完成 ━━━

最终报告：{行业名}_Industry_Report_{日期}.md
总来源数：{N}条
```
