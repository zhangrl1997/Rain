# Card 7/8：最终校验

这是公司研究的最后一张卡。不写新内容，做完整报告的质量校验。

## 你的任务

读完整报告 → [N]校验 → 参考文献校验 → 跨章连贯性检查 → 格式审校 → 输出最终文件

## 工作流

### 1. 读取完整报告

读取：
- `{report_dir}/report_partial.md` — 全部 11 章
- `{report_dir}/sources.md` — 所有来源
- `{report_dir}/{公司名}_Financial_Model_{日期}.xlsx`（如有）
- `../../research-methodology/references/workflow.md` — 校验规则

### 2. [N] 编号校验

1. 提取报告所有 `[N]` 标记，去重排序
2. 与参考文献表逐一核对
3. 检查双向覆盖：每个 `[N]` 在表中有条目？每个条目在正文被引用？
4. 如果存在财务模型，确认模型中的引用标注也纳入统计

### 3. 参考文献核验

1. 按 1→N 顺序排列，不分组
2. 格式：`[N] 标题 — URL`
3. 移除注释类脏数据（无 URL 的行）
4. 检查重复来源

### 4. 跨章连贯性检查

1. 各章逻辑连接是否自然？
2. 关键数据和结论是否一致？（Ch1 的收入与 Ch9 的 TAM 是否匹配？Ch10 的风险 vs Ch8 的竞争是否关联？）
3. 有无重复内容？
4. [N] 编号连续不冲突
5. Ch11 横纵总结是否有效利用了前 10 章的分析成果？

### 5. 格式审校

1. 标题层级完整无跳级
2. 表格对齐标记完整
3. 报告头部信息完整
4. 无锚点链接、无脚注
5. 推测内容标注 `[推测]` 或 `（作者判断）`
6. 模糊时间替换为具体年份

### 6. 输出最终报告

- `{report_dir}/{公司名}_Research_Document_{日期}.md`
- **读取 `.card-progress` 中的 `completed_cards` 列表**，自动生成进度条：已完成→✅，未完成→⬜。不要手动输入 ✅/⬜，全部从进度文件推导
- 更新 `.card-progress` 标记全部完成

## 完成后

输出最终校验报告：

```
━━━ 最终校验报告 ━━━

✅ 章节：11/11 完整
✅ [N]编号：共{N}条，连续无中断
✅ 参考文献：{N}条，全部可访问
✅ 跨章一致性：通过（{N}处微调）
✅ 格式审校：通过
✅ 财务模型：{有/无} — 勾稽校验通过
⚠️ 推测标注：{N}处标为推测

━━━ 项目完成 ━━━

最终报告：{公司名}_Research_Document_{日期}.md
{财务模型：{公司名}_Financial_Model_{日期}.xlsx（如有）}
总来源数：{N}条
```
